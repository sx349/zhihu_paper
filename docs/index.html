知乎论文助手

v0.5.1 GitHub 仓库

在论文页面识别当前论文，并连接知乎上的相关讨论。

Chrome / Edge 开发者模式

  1. 从 GitHub Releases 下载 zhihu_paper.zip 并解压
  2. 打开 chrome://extensions，开启右上角的「开发者模式」
  3. 点击「加载已解压的扩展程序」，选择解压得到的 zhihu_paper 文件夹

使用说明

  • 本插件通过浏览器中的知乎登录状态调用搜索与直答，使用前请确保已登录知乎
  • 点击工具栏图标或论文页面上的浮窗按钮打开侧边栏（Firefox 仅支持工具栏图标）
  • 知乎开放平台的 Access Secret 为备用通道，可在 developer.zhihu.com/profile 生成后填入设置页
  • 安装或更新插件后，请刷新已打开的论文页面
  • 搜索结果和直答解读均缓存在浏览器本地以避免重复调用，如有需要可手动刷新

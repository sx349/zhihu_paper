# 知乎论文助手 · 使用说明

> 在论文页面连接知乎讨论

Chrome / Firefox 插件：在论文页面识别当前论文，并连接知乎上的相关讨论。

---

## 一、安装与配置

- 安装方式见 <https://sx349.github.io/zhihu_paper#install>
- 首次安装会自动打开设置页；之后可右键插件图标 →「选项」进入
- **目前所有功能通过浏览器的知乎登录状态即可使用，无需额外配置**
- 开放平台 Access Secret 仅作为备用通道（可选）；如需使用，请前往 [developer.zhihu.com/profile](https://developer.zhihu.com/profile) 生成，配置后仅保存在本地浏览器
- 安装或更新插件后，请刷新已打开的论文页面

---

## 二、功能

### 当前支持站点

支持站点列表见 <https://sx349.github.io/zhihu_paper#sites>。

### 侧边栏面板功能

- **「论文信息」**：标题、作者、期刊、年份、DOI / arXiv ID、摘要
- **「本文作者在知乎」**：显示论文作者的知乎账号（开发中，目前仅读取预置数据库）
- **「相关问题」**：来自知乎论文关联问题接口与按论文标题检索
- **「相关回答/文章」**：来自按论文标题检索
- **「论文解读」**：调用知乎直答生成，点击后流式返回，按论文缓存

### 参与知乎讨论

- **「参与讨论」**：跳转至排序最高的关联问题
- **「发起提问」**：弹出提问面板
  - 列出 5 条候选标题（由知乎直答生成），点击任一条填入标题栏，可自由编辑
  - 补充说明已预填论文标题、作者、期刊、链接与摘要，可自由编辑
  - 点击「去知乎提问」后跳转知乎并自动填入，**不会自动发布**，需自行确认后点击「发布问题」
